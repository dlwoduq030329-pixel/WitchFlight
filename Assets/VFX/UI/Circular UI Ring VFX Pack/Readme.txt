Circular UI Ring VFX Pack

This resource pack contains 70 VFX prefabs

This circular UI ring effects, created using Unity's particle system, includes 14 different effects and 5 colors.
7 are one-time effects, and 7 are Loop effects.
You can freely adjust their size.


Unity Version：2022.3.45f1
Render Mode：Built-In & URP


Built-in Shaders: Theoretically compatible with all three render modes (Built-in, URP, and HDRP). 
However, please note that using Built-in shaders in SRP(URP,HDRP) environments may result in lower performance.

URP Shaders: Specifically optimized for the Universal Render Pipeline. 
If your project is URP-based, 
please use the dedicated URP shaders to ensure the best performance and visual quality.

If the effects are not visible when placed on your UI, they are likely being blocked by your UI. 
Please ensure that the UI Canvas's Render Mode is not set to "Screen Space - Overlay", 
as this will block all particle effects. 
Please set it to "Screen Space - Camera", 
and then configure the Render Camera settings accordingly.
